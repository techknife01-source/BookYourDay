# Book Your Day — Frontend Application

Next-generation ticketing and reservation web client built with React 19, TypeScript, Vite, and Tailwind CSS.

## Features
- **Comprehensive Discovery**: Browse Movies, Events, Sports, Attractions, Experiences, and Dining.
- **Interactive Seat Selection**: Real-time cinema and arena seating layout selector with category pricing.
- **Dynamic Pricing & Checkout**: Convenience fees, instant offer discounts, loyalty point redemptions, and digital tickets.
- **Digital Tickets & QR Codes**: Animated pass views, dynamic QR verification, downloadable passes, and ticket transfer workflows.
- **Partner & Admin Portals**: Dedicated portals for event organizers, cinema partners, and platform administrators.

## Installation & Setup
```bash
npm install
npm run dev
```

## Environment Variables
Copy `.env.example` to `.env`:
```env
VITE_API_BASE_URL=http://localhost:3000/api
```
